# Task Management UI

The first UI milestone must provide:

- Quick task creation
- Task list
- Completion checkbox
- Edit task
- Priority selector (P1-P4)
- Due date/time selector
- Duration selector
- Deadline selector
- Subtask creation and nesting
- Delete/recover actions
- Drag/reorder
- Bulk selection and actions
- Clear validation and error states

The UI must not treat client-side state as the source of truth. API responses are authoritative and the client should be designed for optimistic/offline behavior from the start.
