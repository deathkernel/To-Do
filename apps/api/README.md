# API

Backend service for To-Do. The API owns authentication, authorization and task business rules.

## Initial domain
Task Management (Feature 01).

## Planned endpoints
- POST /api/v1/tasks
- GET /api/v1/tasks/:id
- PATCH /api/v1/tasks/:id
- DELETE /api/v1/tasks/:id
- POST /api/v1/tasks/:id/restore
- POST /api/v1/tasks/:id/complete
- POST /api/v1/tasks/:id/reopen
- POST /api/v1/tasks/:id/duplicate
- POST /api/v1/tasks/bulk
