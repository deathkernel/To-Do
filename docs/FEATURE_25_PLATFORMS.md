# Feature 25 — Platforms & Devices

## Scope
- Responsive web application.
- Desktop application boundary.
- Mobile application boundary.
- Push notifications.
- Deep links.
- Device/session registration.
- Cross-device synchronization.
- Installable/PWA capability where supported.
- Platform-specific keyboard shortcuts and navigation.
- Graceful degradation when platform APIs are unavailable.

## Principle
Shared domain logic should remain platform-neutral. Platform adapters own OS-specific capabilities.
