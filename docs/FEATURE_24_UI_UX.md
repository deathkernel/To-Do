# Feature 24 — UI / UX & Customization

## Scope
- Responsive desktop/mobile web UI.
- Light/dark/system themes.
- Accent and appearance customization.
- Compact/comfortable density.
- List, board, calendar and timeline presentation.
- Configurable sidebar/navigation.
- Keyboard shortcuts.
- Accessible dialogs, forms, menus and focus states.
- Responsive touch targets.
- Reduced-motion support.
- Localization-ready date/time/number formatting.

## UX invariants
- Core task actions remain discoverable without customization.
- Keyboard and pointer workflows both remain usable.
- Preferences persist per user/device where appropriate.
