# Feature 27 — Advanced Productivity System

## Scope
- Custom productivity workflows.
- Weekly/monthly review flows.
- Personal planning horizons.
- Goals connected to projects/tasks.
- Time-blocking and workload planning.
- Focus sessions.
- Habit/routine support.
- Workload and capacity signals.
- Productivity dashboards.
- Custom recurring planning rituals.
- Context-based task organization.
- Personal productivity rules without forcing a single methodology.

## Principle
The product should support multiple productivity systems rather than requiring one methodology. Advanced features remain modular and can be enabled independently.
